# Round Cactus

Round Cacti! Does it get any better than that?

Fully compatible with other resource packs! As long as this pack is loaded first/above them in the resource pack list.

Due to changes between 1.12.2 and 1.13+, there are two versions of the pack.

- `Round-Cactus-1.9-1.12.2_VERSION.zip` supports Minecraft 1.9 to 1.12.2
- `Round-Cactus-main_VERSION.zip` supports Minecraft 1.13 to 26.2.

Ignore any incompatibility warnings, it will work just fine! This is because you couldn't define support for specific versions of Minecraft until 1.20.1.
